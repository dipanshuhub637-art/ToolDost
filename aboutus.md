# About Us

Welcome to Tool Dost : Smart Tools & Utilities

Tool Dost is an all-in-one utility app developed by DIPANSHU HUB to make daily digital tasks easier, faster, and smarter.

Our mission is to provide useful tools in one lightweight and easy-to-use application.

Tool Dost includes features like:

- Image Compressor
- Passport Resizer
- Image to PDF
- QR Scanner & Generator
- Unit Converter
- Calculator
- Document Scanner
- Notepad
- Voice Recorder
- Secure Space
- And more useful utilities

We focus on:
- Simple user experience
- Fast performance
- Privacy & security
- Useful everyday tools

Most app data is stored locally on the user's device for better privacy and control.
